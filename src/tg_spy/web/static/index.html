Мои темы

Отслеживаемые темы. Локальный ИИ-агент (слабая модель) сам отбирает из общей ленты посты по тегу/метке и собирает их в хронологию темы — дата и источник, без аналитики.

Создать тему

Тег/метка — по ней агент ищет посты (например Лада Гранта). Краткое описание — что именно имеется в виду под тегом (чтобы модель не отбирала всё подряд); держите его коротким. Интервал — периодичность запуска агента в минутах (по умолчанию раз в сутки: 1440).

Настройки провайдера ИИ

Локальная модель (например Ollama) обслуживает «Мои темы». Укажите адрес провайдера — сайт сам опросит его и подгрузит список доступных моделей. Настройки применяются сразу (перезапуск не нужен).

Настройка часового пояса

Часовой пояс для отображения времени запуска агента в «Мои темы». «Авто» — местное время браузера.
