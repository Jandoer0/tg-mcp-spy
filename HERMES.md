# Настройка для Hermes agent

Hermes Agent имеет встроенный MCP-клиент: он подключается к MCP-серверу при
запуске, сам находит его инструменты и делает их доступными наравне со
встроенными (терминал, чтение файлов и т.д.). Никаких дополнительных
«мостов» не нужно.

tg-mcp-spy общается по протоколу **Streamable HTTP** на одном порту — **8090**.
Адрес эндпоинта: `http://127.0.0.1:8090/mcp`.

## Шаг 0. Сервер должен быть запущен

В каталоге проекта выполните (если ещё не запущено):

```bash
./run.sh start
```

Убедитесь, что открывается http://localhost:8090/ui

## Шаг 1. Пропишите сервер в конфиг Hermes

Откройте файл `~/.hermes/config.yaml` и найдите в нём раздел `mcp_servers:`.
Если он уже есть (там могут быть другие серверы, например `planka`) —
**добавьте наш блок внутрь него, не удаляя существующие**.

```yaml
mcp_servers:
  tg-mcp-spy:                       # любое имя сервера
    url: "http://127.0.0.1:8090/mcp"
    # transport: http   # не обязательно: для url это значение по умолчанию
    timeout: 180                    # необязательно
```

Если раздела `mcp_servers:` в конфиге нет вообще — добавьте его в любое
место файла (с тем же отступом, что и другие ключи верхнего уровня).

> 💡 Если сервер запущен на другом порту (например, 8091), укажите его:
> `url: "http://127.0.0.1:8091/mcp"`.

## Шаг 2. Перезапустите Hermes Agent

Горячей замены нет — нужен перезапуск агента (exit и снова запустить, либо
перезапустить сервис/контейнер Hermes, через который вы с ним общаетесь).

## Шаг 3. Проверьте, что сервер подхватился

```bash
hermes mcp list
```

Должна появиться строка примерно такая:

```
  Name             Transport                      Tools        Status
  ──────────────── ────────────────────────────── ──────────── ──────────
  tg-mcp-spy       http://127.0.0.1:8090/mcp      all          ✓ enabled
```

Проверить соединение и увидеть список инструментов можно командой:

```bash
hermes mcp test tg-mcp-spy
```

## Как теперь пользоваться

Инструменты MCP регистрируются с префиксом `mcp_{имя_сервера}_{имя_инструмента}`.
Для нашего сервера (имя `tg-mcp-spy`) это, например:

- `mcp_tg_mcp_spy_add_channel_tool` — добавить Telegram-канал
- `mcp_tg_mcp_spy_add_rsshub_channel_tool` — добавить канал через RSSHub
- `mcp_tg_mcp_spy_query_posts` — получить свежие посты
- `mcp_tg_mcp_spy_list_sources_tool` — список всех подписок

Просто просите агента в обычном виде, например:

> «Подпишись на канал durov и покажи, что он писал за последнюю неделю»

Агент сам вызовет нужные MCP-инструменты.

## Альтернатива: добавление через CLI

Вместо ручного редактирования можно запустить интерактивный мастер:

```bash
hermes mcp add
```

и выбрать добавление HTTP-сервера с URL `http://127.0.0.1:8090/mcp`.
Результат будет тот же — запись в `~/.hermes/config.yaml`.

## Возможные проблемы

- **«No MCP servers configured» / сервер не виден** — проверьте отступы YAML
  и что ключ называется именно `mcp_servers` (не `mcp` и не `servers`).
- **«Failed to connect … tg-mcp-spy»** — сервер не запущен или не на том порту.
  Проверьте `./run.sh status` и откройте http://localhost:8090/ui в браузере.
- **Инструменты не появляются** — перезапустите Hermes Agent (см. Шаг 2).
